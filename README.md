# frontiercreatives.design

The Frontier Creatives website. Static, single file, zero build.

## Stack
Plain HTML/CSS/JS in `index.html` (design system inlined). Deployed on Vercel.

## Deploy
Pushes to `main` auto-deploy via Vercel to https://frontiercreatives.design.

## Files
- `index.html` — the site
- `vercel.json` — security headers + caching
- `robots.txt`, `sitemap.xml` — discovery
- `favicon.svg`, `og.jpg` — brand assets

Design system: https://github.com/FrontierCreatives/design-system
